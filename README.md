# Qadaa — تتبع الصلوات الفائتة وقضاؤها

تطبيق أندرويد (Kotlin + Jetpack Compose) لتتبع الصلوات الفائتة بالأيام المحددة وقضائها.

## بناء ملف APK عبر GitHub (دون Android Studio)
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع كل محتويات هذا المجلد (بما فيها المجلد المخفي `.github`) إلى الفرع `main`.
   إن لم يُرفع `.github` عند السحب والإفلات، فاستخدم Add file ← Create new file واكتب المسار
   `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب **Actions** وانتظر اكتمال "Build APK" (بضع دقائق). يمكنك أيضاً تشغيله يدوياً (Run workflow).
4. افتح عملية البناء الناجحة ونزّل **Qadaa-debug-apk** من قسم Artifacts، ثم فك ضغطه لتحصل على `app-debug.apk`.
5. انقله إلى الهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف).

إن فشل البناء فانسخ نص الخطأ من صفحة Actions وأرسله لإصلاحه.
